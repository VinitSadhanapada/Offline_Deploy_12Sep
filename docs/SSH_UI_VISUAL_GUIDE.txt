┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: PHYSICAL CONNECTION                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────┐                              ┌─────────────────┐
    │   Laptop    │ ──────Ethernet Cable──────── │  Raspberry Pi   │
    │             │                              │  (In the Field) │
    └─────────────┘                              └─────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: FIND PI'S IP ADDRESS                                                │
└──────────────────────────────────────────────────────────────────────────────┘

    Common IPs:  192.168.1.100  |  192.168.4.1  |  10.0.0.1
    
    Or scan: arp -a | grep -i "b8:27:eb\|dc:a6:32"

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: CONNECT VIA SSH (From your laptop terminal)                         │
└──────────────────────────────────────────────────────────────────────────────┘

    $ ssh pi@192.168.1.100
    password: raspberry (or your configured password)

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: LAUNCH TERMINAL UI (Once connected to Pi)                           │
└──────────────────────────────────────────────────────────────────────────────┘

    pi@raspberrypi:~ $ cd ~/Desktop/offline-setup-12Sep
    pi@raspberrypi:~/Desktop/offline-setup-12Sep $ ./terminal_ui.sh
    
    ─ OR ─
    
    pi@raspberrypi:~/Desktop/offline-setup-12Sep $ python3 terminal_meter_ui.py

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: DOWNLOAD DATA (Exit UI with Q, exit SSH, then on your laptop)       │
└──────────────────────────────────────────────────────────────────────────────┘

    METHOD 1: Use the export feature
    ─────────────────────────────────
    1. In UI, press [2] Export CSV Data
    2. Copy the scp command shown
    3. Press Q to exit UI
    4. Type: exit (to leave SSH)
    5. Paste the scp command on your laptop
    
    METHOD 2: Direct SCP
    ────────────────────
    $ scp pi@192.168.1.100:~/Desktop/offline-setup-12Sep/data/csv/*.csv ./
    
    METHOD 3: Use helper script
    ───────────────────────────
    $ ./download_meter_data.sh 192.168.1.100
    (Interactive menu will guide you)

┌──────────────────────────────────────────────────────────────────────────────┐
│ QUICK TIPS                                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

    ✓ Terminal should be at least 80x24 for best display
    ✓ Use xterm-256color for full color support
    ✓ Add alias to your laptop: alias pi-meter='ssh -t pi@IP "cd ~/Desktop/offline-setup-12Sep && python3 terminal_meter_ui.py"'
    ✓ For continuous monitoring: In UI press [1], use another terminal for downloads
    ✓ Export feature (option 2) prepares files and shows exact commands with your IP

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

    PROBLEM                      SOLUTION
    ───────────────────────────────────────────────────────────────────────────
    Can't connect via SSH        • Check Ethernet cable
                                 • Verify IP: ping 192.168.1.100
                                 • Ensure SSH enabled: sudo systemctl start ssh
    
    Colors not showing           • Set terminal: export TERM=xterm-256color
                                 • Use terminal that supports colors
    
    Screen too small             • Resize terminal to 80x24 minimum
                                 • Zoom out in terminal app
    
    No data showing              • Press [6] to start manual reading
                                 • Check [4] System Status
                                 • View [7] Logs for errors
    
    Download fails               • Verify Pi IP address
                                 • Check SSH access first: ssh pi@IP
                                 • Use [2] Export to get exact command
